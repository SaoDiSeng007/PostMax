# PostMax

本地运行的 API 测试工具，类似 Postman / Apifox。前后端分离，后端只做请求转发。

除了单个请求的调试，还带一条**数据驱动的自动化**：把若干请求串成方案，用一份表格喂数据，一次跑完并出报告。

---

## 运行

```bash
pip install -r requirements.txt
python run.py
```

Windows 上也可以直接双击 `启动PostMax.bat`（就是 `python run.py`，启动失败时会停住，让你看清报错）。

后端从 59721 起往后找一个空闲端口（最多试 10 个），并自动打开浏览器；不想让它自动开就设 `POSTMAX_NO_BROWSER=1`。服务**只监听 `127.0.0.1`** —— 同一个局域网里的别人访问不到，存档也不会被外人读到。

> **别直接双击 `index.html`。**
> 页面用的是 ES Module，`file://` 协议下浏览器会直接拦截模块加载；
> 而且所有接口都是相对路径 `/api/...`，必须由后端把页面发出来才能工作。

数据存在 `data/data.json`，就是一个能直接打开看的普通 JSON 文件 —— 删掉它就会回到空白状态。

**第一次打开是空的**（没有预置任何示例数据）。大致顺序是：

1. 建一个项目 → 进项目后建目录和请求
2. 去「环境变量」页建一个环境，把要用的变量配上（每个环境下有「变量分组」和「用户账号」两级，用户级的同名变量会覆盖环境级）
3. 请求里用 `{{变量名}}` 引用
4. 想让一组请求按数据反复跑，切到左侧「自动化」建方案

网络相关的选项（超时、证书校验、重定向）是全局的，在左下角的「设置」里改。

### 前端单元测试

前端是无构建的原生 ESM，测试直接用 Node 内置的 test runner 跑（所以 `package.json` 里只有一句脚本）：

```bash
npm test        # 等价于 node --test tests/
```

覆盖的都是不碰 DOM 的纯逻辑，按模块分文件：自动化那几条「出错了也不报错、只是结果悄悄不对」的规则、断言的执行语义、接口树的老存档迁移与增删改移、**勾选范围与三态**（折叠不算筛选、搜索才算）、变量名与中文列名、变量插入写回输入框的位置、CSV / curl 解析、OpenAPI 的集合导出与「导出再导入」往返、标签页的关闭确认与批量关闭、「存到哪个目录」、分隔条算术、主题接线。

又补了几类**专治「悄悄不对」**的：`plan-scope` 钉「一个步骤跑几遍」的判定（判错的两种表现都很安静：登录跑 N 次互踢 token、或后面每一步都在用第一行的数据）；`run-stats` 钉运行页那几个数字的口径（进度分母是**预期总步数**、超时步骤不算进平均耗时、全局步骤也计入通过失败数）；`contract` 钉前后端三对「双写常量」（存档版本、落盘键、默认超时）读出来必须相等 —— 只靠注释提醒迟早漂移；`script-after` 钉后置脚本的产出与引用口径、报告里日志的摊平顺序、`x-posmax-after-script` 的导出回导；`script-suggest` 钉补全的触发与替换（`env.get('` 里补变量名、`env.` 补成员、插完光标落在引号中间、注释里不打扰）。`wb-tools` 钉工作台那几件工具：MD5 的标准向量与填充边界、路径拼与取的互证、文本 diff 的边界、随机值采样的均匀性。

两个「跨层」的特别说明一下：`script-api` 把 **worker 源码在 Node 里真跑一遍**（造一个 `self`、照实现 `importScripts` 把真 CryptoJS 加载进去），再从沙箱内部问出它到底暴露了哪些成员，与补全词表逐项对 —— 补全许诺了沙箱里没有的东西，比没有补全更坑；`caret-place` 钉候选浮层往哪儿摆（第一项要与光标同一行、窗口底部翻上去、横向收边、坐标不为负）。

另有两条静态体检：`templates` 把所有组件模板真编译一遍（无构建项目里模板语法错了就是白屏），`theme-css` 检查样式表括号配平、`var(--x)` 都有定义、深色那套覆盖了关键变量。

后端测试用标准库 `unittest`（不引入新依赖）：

```bash
python -m unittest tests.test_storage tests.test_proxy
```

覆盖存档的读-改-写与 `revision` 冲突、备份轮转，以及响应读取的三档限制（保留上限 / 统计上限 / 读取总时长）。

## 功能

**请求**

- 方法 + URL，Params 表格与查询串双向同步
- URL 里的 `{pathParam}` 会抽出「路径参数」一栏单独填，值支持 `{{变量}}`
- Headers 表格；Body 支持 JSON / Text / XML / Form（Form 为键值表格）
- **前置 / 后置脚本**：都在 Web Worker 沙箱里执行、超时可强制终止；内置 CryptoJS，兼容 Postman 的 `pm.environment.*` 写法。后置脚本多一个 `response`（`status` / `statusText` / `time` / `size` / `headers` / `body` / `json`），可以拿真实响应里的字段写变量
- **脚本编辑器有代码补全**：`env.` / `console.` / `response.` / `CryptoJS.enc.` 点出来就是成员与签名；选方法会连括号引号一起插、光标停在引号里并接着给出变量名；打字母给根对象与 JS 关键字，行注释和字符串里不打扰。词表（`scriptApi.js`）与沙箱实际暴露的 API 由测试逐项对齐，前置不补 `response`
- **控制台**：脚本里的 `console.log / warn / error` 输出到响应区的「控制台」一页 —— 按等级上色、对象能折开看、每条带出处（哪个请求 / 方案第几步，前置还是后置）。**每次发送前清空**，只留这一次的输出；单次运行最多留 200 条、会话总共 1000 条，超出的丢最旧的并如实标出丢了多少
- 变量插值 `{{var}}`：输入框里高亮显示，敲 `{{` 弹出候选，也可以从按钮插入；取不到值的变量标红
- **系统变量**：`{{$timestamp}}` / `{{$timestampMs}}` / `{{$datetime}}`（本地时间 `YYYY-MM-DD HH:mm:ss`），不用配环境就能用。时间可以带偏移，偏移直接写在名字里 —— `{{$datetime-8h}}`、`{{$datetime+2h30m}}`、`{{$datetime-1d12h}}`（单位 m 分钟 / h 小时 / d 天，可以叠着写）；「插入数据」浮层顶上那个框就是干这个的，**敲什么偏移就实时显示算出来的时间**，写错了当场说明原因（连「大到算不出正经时间」这种也算写错），不会悄悄插进去一个取不到值的变量
- **变量能顺手做个 SHA-256**：`{{源|sha256}}` 会把「源」算出来的值再哈希一遍。源可以是变量名，也可以直接写单引号包起来的明文 —— `{{appSecret|sha256}}`、`{{'Vss_2024'|sha256}}`、`{{'Vss_2024'|sha('sha256')}}`、`{{$timestamp|sha256}}` 都成立。**明文不用先去环境里配一个变量**，省掉「在别处转好再粘回来」这一步。哈希是同步算的（`sha256.js`，纯 JS 实现），所以预览、发送、导出 curl 三处的表现完全一致
- 变量名的规则只有一份（`vartoken.js`），支持中文列名
- curl 双向：粘贴 curl 解析成请求，当前请求反向生成 curl
- **发送中可以停止**：按钮发送中变「停止」，点了就不等这次响应（不用再干等到超时）；取消不算失败、也不进历史
- **发不出去时说得清是哪一跳断的**：连接失败会给「连不上哪台机器、为什么」，而不是贴一段库的内部报错。而且如果这次请求是**经代理**发出去的，会把代理点名写出来 —— 代理可能来自环境变量 `HTTP_PROXY` / `HTTPS_PROXY` 或 Windows 的系统代理设置，这两处都不在界面上，不说出来就没人想得到。实测踩过：代理那一跳死了，界面上写着「连不上 127.0.0.1：对方拒绝连接（服务没起来，或者端口不对）」，而被测服务好端端的

**响应**

- 状态码、耗时、大小
- 页签：**Body / Headers / 实际请求 / 断言 / 控制台**（最后一个是脚本的输出，见上）
- JSON 折叠树 / 原始文本两种视图；响应内搜索，命中的字符才高亮，可上下跳转
- 响应头表格；「实际请求」标签页显示**真正发出去的**请求（含 requests 自动补上的 User-Agent、Accept 等）
- 响应体超过 10MB 时只显示开头一段；为统计真实大小会继续读，最多读到 50MB；整个读取阶段最多 20 秒，到点中止（阈值都在 `backend/proxy.py`）。三种提前停下的原因会在界面上分开说清
- 一键复制完整响应
- 展示区可以点出光标、拖选复制，但改不动内容

**组织与数据**

- 项目 → 目录（可无限嵌套）→ 请求，支持新建 / 重命名 / 删除 / 复制
- 从本地 OpenAPI 文档（YAML / JSON）导入：自动拆成目录与请求，导入前先给预览（列出会导入哪些、哪些被跳过）
- 导出 OpenAPI 3.0（YAML / JSON）：范围二选一（全部 / 部分），可选把环境与账号内嵌进同一份文档（明文，勾选时有警示）；导入会把目录层级、同级次序、停用行与环境账号一并还原（走 `x-posmax-*` 扩展字段，导出再导入不丢配置）
- 项目 JSON 备份：项目卡片可复制 / 导出 / 导入（`<项目名>.posmax.json`）—— 导出含接口树、方案（含测试数据）、历次运行与该项目历史；导入只新增不覆盖，同名加 `(2)` 后缀。「导出 OpenAPI」只是接口文档，不含方案与测试数据
- **勾选与批量**：请求行、目录、「未分组」、顶部「全选」四类勾选框一个口径 —— 每格只管自己那一批，三态（全勾 / 半选 / 空）按「这批是不是都勾上了」判；**折叠不算筛选**（折起来的目录里的请求照样在「全选」范围里），搜索才算（范围收窄成命中的）。勾选集合随时按现存请求对账，删请求 / 换项目都不会留下影子勾选
- **勾选之后**：主区左上角浮出一条「已选 N ｜ 移动到目录 ｜ 删除 ｜ ✕」，同时主区虚化退后（**只盖这一栏**，侧栏、功能列、浮条不动）。浮条不占布局，出现与消失都不推动任何内容；「移动到目录」是折叠的层级菜单，并标出这几条眼下在哪个目录
- 环境变量：多环境，每个环境下有变量分组和用户（认证信息），用户级同名变量覆盖环境级；被账号盖住的那些行挂着「被账号覆盖」角标，悬停说明实际生效的是谁的值
- 历史记录：按时间倒序、精确到毫秒，点击回填；保留最近 200 条
- 改动自动保存到后端（防抖 400ms），顶栏有同步状态提示

**自动化**

- **方案**：一组有序步骤，本质上是一条流程；左栏按「目录 → 方案」两级组织，方案可以直接拖进目录
- **步骤**：从接口树里挑请求加进来（也可以先加空步骤），拖拽排序，点哪一步就地展开成接口编辑器；每行右边挂着上一次的执行结果
- **执行顺序**：**一个接口把它所有数据行跑完，才轮到下一个接口**（`接口1: 行1→行2→…→行N`，再 `接口2: …`）。每个接口跑几遍 = 数据行数（步骤行上直接写着「5 行」），没有测试数据时跑 1 遍。单个请求失败会原地重试，重试用完仍失败也不打断后面的接口
- **测试数据**：方案自带一张**可编辑的表**（可手动建，也可导入 CSV）；每行有自己的变量表，行与行之间不会互相串值
- **只跑前 N 行**：调试时先跑几行看看，不用等整张表
- **方案变量**：方案自己有一份可写变量表；环境 / 账号对方案是只读的，测试不会反过来改掉手配的环境变量
- **运行设置**（属于方案，跟方案一起保存）：并发 1–6、请求间隔、失败重试次数（默认 2）、单请求超时、出错是否继续
- 运行期间按钮变「停止」，能真的停下来
- **报告**：按步骤汇总通过 / 失败，可筛选、导出 CSV、一键复现失败步骤；每个方案保留最近 10 次运行，可以来回对比
- 并发上限是 6 —— HTTP/1.1 下浏览器对同源最多开 6 个连接，设更大只是在浏览器里排队

**断言与提取**

- 声明式断言：目标（状态码 / 响应耗时 / 响应大小 / 响应头 / JSON 路径）→ 操作（等于 / 不等于 / 包含 / 存在 / 小于 / 大于 / 正则匹配 / 类型是 / 长度 / 符合 schema）→ 期望值，发送后自动执行；正则可用 `/pattern/flags` 写法，schema 支持 type、required、properties、items、enum、数值与长度区间、pattern
- 声明式变量提取：从响应 JSON / 响应头 / 正文正则 / 状态码取值写进变量，供后续请求引用
- 自动化里「步骤失败」的口径：连不上、超时、状态码 ≥ 400、断言不过都算；被手动叫停不算，不触发重试

**工作台**

- 不碰项目数据的本地工具台：每个工具都在浏览器里算完，结果只经「复制 / 下载」带走 —— 不读存档、不写任何项目数据（会话级，刷新就没了）
- 左栏列工具、主区是当前那一个；加工具只动两处（`workbench.js` 的清单 + `WorkbenchView` 的映射）。进去就有东西，没有「先生成一下」这一步
- **图片 → Base64**：选文件 / 拖进来 / **直接粘贴截图**（做接口时最常用的一种），一次可进多张；输出整份 data URL 或逗号后面那截纯 base64，每张单独复制或下载；超 2MB 提醒一句
- **时间戳互转**：只有**北京时间**与 **UTC** 两条线（没有「本地时间」，机器时区不影响），四行结果 北京时间 / UTC / 毫秒 / 秒，整行点击复制，没输入时实时走秒。点开第一行是自画的**六列选择面板**（年 / 月 / 日 / 时 / 分 / 秒各带表头，打开时每列滚到当前值）—— 原生 `datetime-local` 的时分秒列在 shadow DOM 里，加不了表头也摆不平六列；点哪列改哪列即时生效，「确定」和点面板外的空白是同一个效果（面板浮在第一行右端，不顶下面的内容）
- **JSON 取路径**：左边贴原文、右边结构树，**整行任意位置**单击复制 `data.list[0].name` 这种断言路径（与 `assert.js` 的 `getByPath` 同一套语法）；鼠标悬停会说明「鼠标左键单击复制路径」，复制不了的行（键带点 / 方括号、根节点）会说明原因。容器行的箭头只管展开收起 —— 它是唯一的例外；叶子行那一小条空白也照样复制
- **UUID / 随机值**：打开就有；UUID 可选大写、去横杠（默认小写去横杠），随机串可选字符池与长度，整行点击复制
- **正则测试**：边打边算（缓 200ms），标出命中与分组，配合 `matches` 断言用
- **哈希**：SHA-256（WebCrypto）/ MD5（`md5.js` 自带实现，WebCrypto 不收 MD5），可贴期望值自动比对
- **文本对比**：逐行 LCS、行号标注，可先按 JSON 归一（键排序）再比

## 界面

- **主题**：浅色 / 深色两套，在「设置 → 主题」里切（跟着 `settings.theme` 存下来）。实现是给 `<html>` 写 `data-theme`，深色那套只覆盖 CSS 变量，组件规则一条不动
- **浮层**：下拉菜单走半透明「玻璃底」（背后 `backdrop-filter` 虚化，不支持它的浏览器退回实底）；弹层遮罩压暗 + 轻虚化，并把左边那一栏让出去，所以弹窗落在主区中央、不压侧栏。**要挑东西的弹层（挑接口、导出）钉住上沿** —— 内容变高只往下长，不跟着上下跳。勾选接口期间主区整体虚化退后（同「只盖这一栏」）
- **键盘**：能点的地方都能聚焦，`Enter` / `空格` 触发（侧栏树、请求与方案标签页、方案步骤行、报告行、历史行、环境页、项目卡片、工作台工具行、四个弹层、`⋯` 菜单）；弹层打开时焦点搬进去、`Tab` 在里面循环、关掉还给原来的元素；两条分隔条聚焦后可用方向键调尺寸
- **标签条**：装不下时可以按住鼠标左右拖（也能滚），右端那颗「＋」在溢出时钉在行末不会被拖走；切标签页只滚到「看得见」为止，从「＋」菜单跳到被裁掉的那个能看见它
- **可读性**：三档文字灰度在浅色和深色下都过 WCAG AA（正文 4.5:1）；红字压在浅红底上另走 `--red-text`；方法名配色按「选中行的浅靛底」取值。可点热区不小于 16px、图标按钮 24px
- **窄屏**：≤1180px 侧栏封顶、≤900px 侧栏整行铺开、主区另起一行；桌面布局不受影响

## 技术栈

- **前端**：Vue 3，直接用浏览器 ESM 版本，**没有构建工具**；第三方库全部下载到 `frontend/vendor/`，不走 CDN，离线可用（通过 `index.html` 的 importmap 映射成裸模块名）
- **后端**：Python + Flask + requests。一个进程同时干三件事：转发请求、读写数据文件、发静态文件
- **存档**：单个 JSON 文件，原子写（先写临时文件、`fsync` 再替换）+ 自动备份（同一份最多每 5 分钟留一次，保留最近 10 份）+ `revision` 乐观并发（别处改过就拒写并回 409）。存档格式版本比代码新时自动转只读，**不会用旧代码把新字段抹掉**
- 前后端同源，所以前端直接 `fetch('/api/...')`，没有跨域问题
- **测试**：Node 内置 test runner（`npm test`），只测不碰 DOM 的纯逻辑

## 接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/state` | 读取全部存档（连同 `revision`） |
| PUT | `/api/state` | 整份 / 部分覆盖保存（按键合并），返回 `{"revision": n}`；发现别处改过（`baseRevision` 对不上）就回 409 且**不写** |
| POST | `/api/proxy` | 转发请求 |
| GET | `/api/health` | 健康检查 |
